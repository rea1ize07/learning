## 建议顺序

**如果你的目标是尽快接上科研**（信通背景）：

1. **04** — 这是你的主场，不是入门书但读得最快，单卡就能做实验
2. **00** 的第 2、5 章 — 补 LLM 架构地图
3. **00 → 05 → 06 → 07 → 08** — 自演化这条线按时间顺序读，能看到概念怎么一步步收窄

**如果只是建立全景**：00 → 01 → 02 → 03，四份大概 15 小时。

**05 vs 08 先读哪个**：先 05。08（RSI）是终点，05 是它脚下的方法地图。

## 两条阅读提醒

1. **每份笔记的「对我的价值」和「怎么读」两节是结合读者背景写的**（通信/信号处理出身、AI 初学、需要在研一产出成果），不是原文内容，别当论文结论引用。
2. **00 号笔记有特殊局限**：官方 PDF 用了 Adobe-GB1 CID 字体且缺 ToUnicode 映射，`pdftotext` 提取不出任何中文（35 万字符里 0 个汉字），Read 工具也无法渲染 PDF。该笔记是靠**解析 PDF 书签树（224 个，UTF-16 存储）+ 官方站与 GitHub README** 重建的目录与章节说明，**没有读到正文**。章节骨架可信，但「每章讲什么」的描述有推测成分——请以实体书/PDF 阅读器里的正文为准。
